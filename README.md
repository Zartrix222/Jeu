# PROJECT: INDUSTRIA

Jeu mobile (Android / iOS) de simulation industrielle en monde ouvert, en troisième personne.
Unity 6 · URP · C#.

## Documentation
- [Architecture technique](Docs/ARCHITECTURE.md)
- [Étape 1 — Créer le projet Unity](Docs/ETAPE_01_CREATION_PROJET.md)

## Dépôt
- Le projet Unity est à la **racine** du dépôt (`Assets/`, `Packages/`, `ProjectSettings/`).
- Les binaires lourds (modèles, textures, sons) passent par **Git LFS** : exécuter `git lfs install` une fois sur chaque machine.
